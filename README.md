Cafe Menu API

Мой первый API, залитый на Github

Умеет:
- Показывать список блюд
- Фильтровать по категории и цене
- Добавлять новые блюда

Как запустить:
1. Создать виртуальное окружение: `python -m venv venv`
2. Активировать: `source venv/bin/activate`
3. Установить зависимости: `pip install -r requirements.txt`
4. Запустить: `python app.py`
